Forecasts each GTA VI PlayStation 5 trophy's Exophase earn rate one week after launch, as five quantiles per trophy, from the history of trophy-page reads. A saturating growth curve is fitted per trophy on the logit scale, with a spread that widens with the forecast horizon.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
